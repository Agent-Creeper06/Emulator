# Emulator
## Эта программа является эмулятором для языка оболочки ОС
# Функционал
## Данная программа эмулирует языковую оболочку ОС. Программа поддерживает набор команд, присущих командной строке языка bash. Она способна взаимодействовать с файлами компьютера и выводить их на терминал. Среди поддерживаемых команд есть команды ls, cd, echo, pwd, whoami, env и подобные.
